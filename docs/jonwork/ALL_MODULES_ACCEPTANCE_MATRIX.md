## 验收口径

每个菜单必须依次完成：自动匹配 → 读取当前材料与上游产物 → 以尽量少打断的渐进方式补齐必要信息（不限定问题数或轮次，信息足够即推进）→ Brief 确认 → 真实文件生成 → 文件与内容/视觉校验 → 右侧成果栏出现 → 用户批准最终版。仅路由测试、仅提示词、空文件或聊天文字都不算业务完成。

所有 14 个 Workspace Skill 已补齐统一交付闭环，并通过 Skill Creator 结构校验。自动路由测试覆盖全部菜单，概念效果图不会误匹配为图片转 3D。
