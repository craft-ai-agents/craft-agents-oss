Problem. The path module is shallow — interface is an env read at import time, almost identical to the implementation.

Solution. One OwnedRootPolicy module; callers take a resolved root, never capture env themselves.

  • leverage: one interface, N path call sites
  • seam: tests inject an adapter; production does not read env after boot

Problem. The import module's seam sits on a remote-eligible channel while the implementation walks a local filesystem path.

  • locality: trust check lives with the import module
  • leverage: one deny path for every remote adapter
Notes implementation plan forbids shipping this until security acceptance — record the seam, do not start the Notes plan.
