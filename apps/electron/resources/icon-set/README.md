# ARCHstudio icon-set

Single canonical asset folder for the ARCHstudio app icon. Generated by
`apps/electron/resources/generate-icon-set.mjs` from
`apps/electron/resources/icon.svg`.

## Layout

| File            | Size          | Role                                                                 |
| --------------: | :-----------: | -------------------------------------------------------------------- |
| `icon.svg`      | vector        | Canonical vector source.                                             |
| `icon-16.png`   | 16×16         | ICO / ICNS entry.                                                    |
| `icon-24.png`   | 24×24         | ICO entry.                                                           |
| `icon-32.png`   | 32×32         | ICO + ICNS icp5.                                                     |
| `icon-48.png`   | 48×48         | ICO entry.                                                           |
| `icon-64.png`   | 64×64         | ICO + ICNS icp6.                                                     |
| `icon-128.png`  | 128×128       | ICO + ICNS ic07.                                                     |
| `icon-256.png`  | 256×256       | ICO + ICNS ic08.                                                     |
| `icon-512.png`  | 512×512       | ICNS ic09. Also aliased as `resources/source.png` for back-compat.   |
| `icon-1024.png` | 1024×1024     | ICNS ic10. Canonical `resources/icon.png` and `icon-set/icon.png`.  |
| `icon-2048.png` | 2048×2048     | Marketing / print export only. Not embedded in ICO or ICNS.          |
| `icon.png`      | 1024×1024     | Canonical single-file PNG (electron-builder default).               |
| `icon.ico`      | multi-size    | Windows taskbar / installer. PNG-encoded entries 16–256.             |
| `icon.icns`     | multi-size    | macOS Finder / Dock / installer. PNG-encoded icp4–ic10 (16–1024).    |
| `anim.webm`     | 4s loop       | Animated emblem — VP9 with alpha (marketing / README hero).         |
| `anim.apng`     | 4s loop       | Animated emblem — looping APNG (splash tester / web hero).          |
| `diag/*.png`    | snapshots     | Per-run visual sanity renders (overwritten each generation).         |

## How to regenerate

```bash
# Static icon-set (PNG ladder + ICO + ICNS)
node apps/electron/resources/generate-icon-set.mjs

# Animated emblem (4s WebM + APNG loop)
bun run anim:generate

# Smaller / lighter variants
bun run anim:generate:256          # 256x256 frames
bun run anim:generate:24fps        # 24fps instead of 30fps

# custom output directory (skips sync to resources/)
node apps/electron/resources/generate-icon-set.mjs --no-sync --out=./out
```

The animated emblem renderer bakes per-frame transforms into 120
SVG strings (30fps × 4s, 512×512, transparent) and pipes them
through ffmpeg with `-pix_fmt yuva420p` for WebM and `-plays 0 -f
apng` for the looping APNG. Frame math: ring rotates 360° over 4s;
diamond pulses 1→1.25→1 over 2s (two full cycles per loop, returning
seamlessly to the start state at t=4s). The 2s pulse deliberately
differs from the live splash's 1.6s pulse so the static artefact
loops cleanly — a 1.6s pulse would leave the diamond mid-cycle at
the loop seam.

After regeneration the script copies `icon.svg`, `icon.png`, `icon.ico`,
and `icon.icns` into `apps/electron/resources/` so
`electron-builder.yml` picks them up without changes. We **copy**
rather than symlink because electron-builder snapshots the resources
folder at build time and Windows + electron-builder resolve symlinks
inconsistently across packaging flows; a copy is a guaranteed
frozen-snapshot artefact.

## Why this layout

- `icon.svg` is the single source of truth — the splash screen's
  `SymbolMark` React component renders the same SVG paths in-browser,
  so the static app icon and the live splash symbol stay visually
  byte-identical.
- Win ICO is capped at 256 because the ICONDIRENTRY width/height byte
  is uint8 (0=256). For Windows contexts that need a larger raster
  (Retina taskbars, HiDPI tray), the `icon.png` (1024) is also a
  valid icon source via electron-builder's Linux + macOS targets.
- macOS ICNS includes both the lowercase `icp4/5/6` legacy PNG tags
  and the uppercase `ic07/08/09/10` Big Sur+ tags. Tag legend:
  `icp4=16`, `icp5=32`, `icp6=64`, `ic07=128`, `ic08=256`,
  `ic09=512`, `ic10=1024`.
