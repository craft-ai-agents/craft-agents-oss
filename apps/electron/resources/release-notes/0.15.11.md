## Features

- **A menu for links to local files** — Clicking a link to a file on your computer opened it straight in Craft's preview, with no way to open it in your browser or in its own app. A click now opens a small menu next to the link: **Open in browser** for `.html` and `.htm` files (the app your system opens HTML files with, normally your browser) or **Open in default app** for other files, **Preview here** for files Craft can preview, **Show in Finder** (your file manager on Windows and Linux) and **Copy path**. To skip the menu, hold ⌥ (Alt on Windows and Linux) while you click: the file opens in its default app. Links in the Web UI still open the preview directly, since it can't open files on your computer.

## Improvements

- **The Window menu lists your windows** — On macOS, the Window menu now lists the open Craft windows, so you can bring one to the front from the menu bar. The window in front is checked and minimized windows are marked; with two or more windows open, each is named after its workspace. The in-app browser windows are left out.
