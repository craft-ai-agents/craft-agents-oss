## Features

- **Sign in to MCP servers that reject the OAuth relay** — Some MCP servers only accept a local (loopback) redirect address when signing in, and refuse the Craft Agents relay with an error like "only HTTP loopback callbacks". Add `"oauthRelay": false` to the source's `mcp` block to send the sign-in straight back to the app on `localhost` instead. Leave it unset to keep using the relay. See **Sources → MCP servers → Authentication** in the docs.

- **Request OAuth scopes for MCP servers** — Sign-in to an MCP server never asked for specific scopes, so servers that grant less by default (for example read-only) issued tokens that couldn't use their write tools. List the scopes you need in the source's `mcp` block, for example `"scopes": ["app:read", "app:write"]`, and sign in to the source again. Leave it unset to keep the server's default scopes. See **Sources → MCP servers → Authentication** in the docs.
