## Features

- **Crafty works in remote workspaces** — When the Craft window you used last shows a workspace on a remote server, Crafty now works there: new sessions are created on that server (labelled `crafty`), the panel's model menu offers that server's connections, **Send Crafty Here** is in the menu of its sessions, and Rewrite and Translate run on its connections. Until now Crafty quietly put these questions in a local workspace. With more than one workspace, the panel's session chip and the pie's **Send to** say which workspace a new session goes to. Rewrite and Translate need the server to run this version or later; with an older server everything else works, but a Crafty session shows in Craft's session list only once it starts answering, and without its `crafty` label until the app restarts.

## Improvements

- **New chats show up in every window right away** — A chat created in one window now appears at once in the other windows of the same workspace, in the Web UI and on other devices connected to the same server, with its title and labels. Before, it appeared there only after its first message, and without its labels.

## Bug Fixes

- **Crafty's first question works with skill and source suggestions on** — With **Skill and source suggestions** turned on for the decision model (Settings → AI → Decision model, Advanced settings), Crafty's first question in a new session failed with "Cannot read properties of null (reading 'hidden')".

- **Crafty follows a window that switched workspaces** — After you switched the workspace shown in a Craft window, Crafty kept sending new questions to the previous one until you focused another window.

- **Send Crafty Here from another workspace while Crafty is open** — Choosing **Send Crafty Here** on a session in another workspace while Crafty's panel was open moved the panel to that session, but its answer never showed in the panel. The open panel now keeps its session, and Crafty goes to the one you chose the next time you open it.

- **Crafty's errors read cleanly** — Errors from Crafty, in its panel and notes and when you use **Send Crafty Here**, no longer start with "Error invoking remote method …".
