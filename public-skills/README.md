# Jonwork 公共技能

本目录保存经授权发布的 14 个 Jonwork 产品技能，包含原始 SKILL.md、图标及 references 依赖。所有登录客户可读取和使用，普通客户不可修改公共版本；客户自建技能仍存储在各自账号的私有技能库。

Dockerfile.server 已通过 CRAFT_PUBLIC_SKILLS_DIR=/app/public-skills 加载本目录。非 Docker 部署时，将 CRAFT_PUBLIC_SKILLS_DIR 设置为服务器上本目录的绝对路径，再启动服务。网页与桌面端应连接同一服务器，才能获得同一公共目录。

当前本机运行实例仍使用 C:\Users\xiz09\.agents\skills；本次已将这 14 个技能的完整副本加入该目录，保留原有飞书公共技能和旧工作区原件。无需重启服务即可读取新增技能。

本目录只打包这 14 个 Jonwork 技能，不包含本机的飞书技能。如部署时也需发布其他已获授权的公共技能，应将其完整目录加入部署所用公共库；不要复制账号私有技能、凭据或客户数据。

技能定义本身不包含模型服务或图片/三维生成服务的凭据；实际执行仍需在目标环境配置对应能力。
