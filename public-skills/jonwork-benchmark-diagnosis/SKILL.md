# 对标诊断

用同层级证据比较自有方案和参考对象，区分可借鉴要素、不建议迁移内容、迁移风险与差异化机会。

## 统一交付闭环（强制）

- 先读取当前会话、项目、附件、Source 与上游产物，列出已具备、缺失、冲突及不适用材料；不得要求用户重复提供已有信息。
- 缺少会改变结果的参数或必需素材时，每轮最多询问 1–3 个关键问题并给推荐默认值；必需图片/选区/参考对象缺失时必须阻塞对应生成阶段，不得猜测或伪造。
- 生成前回显目标、输入角色、约束、输出格式、选定 Skill 与逐项验收标准；用户已明确批准相同 Brief 时直接继续。
- 输出必须是本技能交付契约规定的真实文件，并同步维护 `deliverable-brief.md` 与 schema v2 `deliverable-manifest.json`；每次修订递增版本且不覆盖已批准版本。
- 生成后打开或解析全部文件，逐项记录可读性、内容/视觉一致性、保护项、禁止项与失败证据。供应商或工具失败时保持 `draft`，只列真实成功文件。
- 只有真实产物存在、验收项全部有通过证据且用户明确批准后才能标记最终版；否则在右侧成果栏保持草稿、待确认或失败状态。


## 调用与路由

- 用户要求方案对标、视觉距离、参考迁移边界、品牌差异或专利避让线索时适用。
- 市场层面的竞品格局用 `@竞品洞察`；只评估单个方案内部质量用 `@方案评估`。

## 界面参数

- `ownDesignImages`：至少一张自有方案图。
- `benchmarkImages`：至少一张参考方案图。
- `comparisonFocus`：可选，重点维度、可借鉴元素、禁止迁移点、差异化目标或专利避让边界。
- 尽量使用同视角、同状态、同版本资料；差异过大时说明不可比项。

## 自动执行

1. 对齐视角、尺度、点亮状态和证据版本，先列不可比条件。
2. 输出总判断和分层评分：定位与价值感、造型距离、识别与细节、差异化空间。评分为专家判断分。
3. 建立对标观察矩阵：轮廓与比例、前脸/界面图形、侧面体块与特征线、细节与制造、CMF 与品牌识别；按产品类型调整命名但保留层级。
4. 分别给出可借鉴、不建议迁移、迁移风险和差异化机会；观察、推断与法律结论严格分开。
5. 形成问题优先级、指导建议和后续工作流；按 [references/deliverable-contract.md](references/deliverable-contract.md) 保存预览与状态。

## 边界

本技能只能提供专利风险线索，不构成侵权或自由实施法律意见。单视角不能确认背面、分缝、结构和真实材质。
