# 竞品洞察

以当前 Craft 任务中的产品和决策目标为起点，自动读取用户洞察、附件和 Sources，直接生成可预览的竞品结果。

## 统一交付闭环（强制）

- 先读取当前会话、项目、附件、Source 与上游产物，列出已具备、缺失、冲突及不适用材料；不得要求用户重复提供已有信息。
- 缺少会改变结果的参数或必需素材时，每轮最多询问 1–3 个关键问题并给推荐默认值；必需图片/选区/参考对象缺失时必须阻塞对应生成阶段，不得猜测或伪造。
- 生成前回显目标、输入角色、约束、输出格式、选定 Skill 与逐项验收标准；用户已明确批准相同 Brief 时直接继续。
- 输出必须是本技能交付契约规定的真实文件，并同步维护 `deliverable-brief.md` 与 schema v2 `deliverable-manifest.json`；每次修订递增版本且不覆盖已批准版本。
- 生成后打开或解析全部文件，逐项记录可读性、内容/视觉一致性、保护项、禁止项与失败证据。供应商或工具失败时保持 `draft`，只列真实成功文件。
- 只有真实产物存在、验收项全部有通过证据且用户明确批准后才能标记最终版；否则在右侧成果栏保持草稿、待确认或失败状态。


## 调用与路由

- 用户提到竞品、对标、品牌比较、市场格局、价格带、差异化或市场空白时适用。
- 显式 `@竞品洞察` 时优先执行；未引用时按意图自动启用，不要求用户选择技能。
- 用户主要在询问用户需求或请求具体设计方案时不要抢占。若用户洞察已经存在，自动继承；不存在时也可先生成假设型竞品初稿。

## 最小输入原则

- 产品明确后即可运行。市场、价格带、目标用户和比较维度优先从当前任务、用户洞察及行业常识推断，不逐字段追问。
- 只有产品类别存在根本歧义或用户要求互相冲突时，才一次性提出一个短问题。
- 多轮对话的最新明确要求优先。不得要求用户重复本任务中已经说明的内容。
- 不使用其他项目的竞品或验收样例作为当前事实。

## 界面参数映射

- `researchTask`：竞品研究任务。
- `market`：国家、地区或渠道；`audienceScenario`：人群与使用情境。
- `focus`：功能、造型、CMF、制造、成本或专利等重点。
- `researchImages`、`documents`：当前任务的竞品图片与文档；`resourceLinks`：每行一个官网、评测、专利或项目链接。
- 高级设置：`lifecycleStage`、`priceBand`、`brandScope`、`constraints`，分别对应生命周期、价格带、指定/排除品牌、技术/供应链/成本约束。

产品明确后自动补齐市场和高级设置并标为假设；用户提供的品牌范围、价格带和排除项必须原样保留。状态 JSON 保存上述字段及来源。

## 自动执行

1. 自动查找并读取 `data/01-用户洞察状态.json` 或用户洞察预览，把 P0/P1 需求转为比较重点；没有上游结果时使用产品任务建立待验证维度。
2. 自动构建直接竞品、替代品和必要标杆。时效性规格、价格和状态优先用当前可用 Source 或网页核验。
3. 维度权重自动生成且合计为 100；允许用户用一句话调整，例如“安全优先，价格弱化”。
4. 缺失规格写 `unknown`，不得把“未公开”判断为“不具备”。事实、推断和建议分层并记录置信度。
5. 生成矩阵、关键取舍、差异空白、机会和验证动作。后续对话读取状态文件，只修订受影响部分并保留稳定 ID。
6. 按 [references/deliverable-contract.md](references/deliverable-contract.md) 生成 Craft 可直接预览的 Markdown 和内部状态 JSON，完成后立即渲染报告预览。

## 渐进式专业会话

1. **快速启动**：产品明确后先生成初稿；产品不明确时只问研究对象。
2. **市场定位**：预览后根据影响度，逐轮确认目标市场、价格带或核心客群；每次最多一个问题，并提供推荐默认值。
3. **对标深化**：再确认直接竞品、替代品、标杆范围和关键比较维度。用户未指定竞品时自动构建代表性样本，不阻塞。
4. **决策深化**：围绕权重、进入策略、差异化空间和实测缺口逐步询问取舍；不要求用户填写完整矩阵。
5. **证据深化**：提示可上传产品资料或指定品牌，但公开检索和 Source 采集由系统完成。

仅询问阻止正确理解或显著改变结论的问题；可推断内容直接形成假设。每轮最多一个问题，最多 3 个选项，最新回答覆盖旧假设且不得重复询问。

用户说“定稿/确认最终版”时，校验权重、来源、时效和引用后生成 `data/final/02-竞品洞察最终报告-vN.md`；后续修改创建新版本。

## 状态

默认标记为初稿，不修改数据库或审批状态。用户未要求时，不额外生成表格文件、PPT 或图片。

## 实时预览（强制）

- 每次生成或修订后覆盖 `data/02-竞品洞察预览.md`，立即读取并在当前回复中渲染 `markdown-preview`。
- `markdown-preview.src` 使用真实绝对路径；禁止输出 `{{SESSION_PATH}}`、相对路径或不可打开的备用链接。
- 预览能力不可用时直接内联完整报告。渲染后简述样本、来源状态和本轮变化，不要求用户再选择下一步。
- 若存在一个高价值专业缺口，可在预览后询问一个具体取舍，并给出系统推荐默认值；禁止宽泛追问。
