# Craft 竞品洞察交付契约

默认生成：

- `data/02-竞品洞察预览.md`：给用户查看的竞品矩阵、洞察和机会。
- `data/02-竞品洞察状态.json`：供后续对话修订和设计提案复用。

Markdown 预览包含：研究范围、样本逻辑、加权维度、竞品矩阵、关键取舍、市场空白、机会优先级、来源置信度和下一步验证。维度权重合计为 100；当前规格和价格带来源与时间；未知值写“未公开/待实测”，不做负向评分。

状态 JSON 保存 Brief、界面字段（任务、市场、人群场景、重点、附件、链接和高级设置）、维度、竞品、矩阵、发现、空白、机会、来源引用、稳定 ID、本轮变化、`conversationDepth`、`answeredQuestions`、`assumedDefaults` 和 `nextBestQuestion`。后续对话优先读取它并同步更新两份文件。

写入后立即使用预览文件的真实绝对路径渲染 `markdown-preview`。不得输出包含 `{{SESSION_PATH}}` 的链接；预览组件不可用时直接展示 Markdown 正文。

若仍有会显著改变市场结论的缺口，预览后只提出一个“专业深化（可选）”问题，并给出推荐默认值；不得重复已回答内容。
