# CMF发散

锁定产品几何造型，通过颜色与材质参考生成可比较的 CMF 方向。

## 统一交付闭环（强制）

- 先读取当前会话、项目、附件、Source 与上游产物，列出已具备、缺失、冲突及不适用材料；不得要求用户重复提供已有信息。
- 缺少会改变结果的参数或必需素材时，每轮最多询问 1–3 个关键问题并给推荐默认值；必需图片/选区/参考对象缺失时必须阻塞对应生成阶段，不得猜测或伪造。
- 生成前回显目标、输入角色、约束、输出格式、选定 Skill 与逐项验收标准；用户已明确批准相同 Brief 时直接继续。
- 输出必须是本技能交付契约规定的真实文件，并同步维护 `deliverable-brief.md` 与 schema v2 `deliverable-manifest.json`；每次修订递增版本且不覆盖已批准版本。
- 生成后打开或解析全部文件，逐项记录可读性、内容/视觉一致性、保护项、禁止项与失败证据。供应商或工具失败时保持 `draft`，只列真实成功文件。
- 只有真实产物存在、验收项全部有通过证据且用户明确批准后才能标记最终版；否则在右侧成果栏保持草稿、待确认或失败状态。


## 调用与路由

- 用户要求换色、换材质、表面处理探索或 CMF 情绪板落图时适用。
- 要改变体块和造型语言用 `@造型融合`；整图环境变化用 `@整图编辑`。

## 界面参数

- `productImage`：必填，主体完整、背景清晰。
- `referenceMode`：颜色与材质分开或综合参考。
- `colorReference`、`materialReference`、`combinedReference`：按模式提供，可选但至少有文字要求。
- `generationContent`：颜色与材质/综合。
- `referenceStrength`：高/低，默认低。
- `cmfRequirements`：产品类型、颜色、材质、纹理、涂层、光泽和表面工艺。
- 输出设置：比例 `1:1`/`3:2`/`2:3`、张数 1–4、质量低/中等/高；默认 `1:1`、1、中等。

## 自动执行

1. 锁定轮廓、比例、部件、特征线和视角；建立颜色分区与材料分区。
2. 从参考图迁移配色关系、色块分布、材质、纹理和表面处理，禁止迁移其造型。
3. 根据参考强度控制相似度，生成指定数量图片；检查几何漂移、材质尺度、光泽逻辑、分区连续性与可制造性风险。
4. 按 [references/deliverable-contract.md](references/deliverable-contract.md) 保存并展示结果。

## 边界

生成图不构成真实色差、材料性能或工艺可行性证明。不得因参考强度高而复制品牌标识或产品形态。
