# 局部改型

锁定整机，只修改用户圈选或明确描述的局部区域，并实际生成可比较的改型结果。

## 统一交付闭环（强制）

- 先读取当前会话、项目、附件、Source 与上游产物，列出已具备、缺失、冲突及不适用材料；不得要求用户重复提供已有信息。
- 缺少会改变结果的参数或必需素材时，每轮最多询问 1–3 个关键问题并给推荐默认值；必需图片/选区/参考对象缺失时必须阻塞对应生成阶段，不得猜测或伪造。
- 生成前回显目标、输入角色、约束、输出格式、选定 Skill 与逐项验收标准；用户已明确批准相同 Brief 时直接继续。
- 输出必须是本技能交付契约规定的真实文件，并同步维护 `deliverable-brief.md` 与 schema v2 `deliverable-manifest.json`；每次修订递增版本且不覆盖已批准版本。
- 生成后打开或解析全部文件，逐项记录可读性、内容/视觉一致性、保护项、禁止项与失败证据。供应商或工具失败时保持 `draft`，只列真实成功文件。
- 只有真实产物存在、验收项全部有通过证据且用户明确批准后才能标记最终版；否则在右侧成果栏保持草稿、待确认或失败状态。


## 调用与路由

- 用户要求修改把手、按键、灯组、开口、局部曲面等具体区域时适用。
- 修改整图环境用 `@整图编辑`；整体造型语言迁移用 `@造型融合`。

## 界面参数

- `productImage`：必填，主体完整、背景清晰。
- `selectionMask`：必填或可从用户明确区域描述中构建；必须能唯一定位修改范围。
- `localReference`：可选，只为圈选部位提供视觉证据。
- `remodelRequirements`：局部目标和保持整体协调的要求。
- 输出设置：比例 `1:1`/`3:2`/`2:3`、张数 1–4、质量低/中等/高；默认 `1:1`、1、中等。

## 自动执行

1. 记录修改区域、保护区域、边界过渡和不可变特征；区域不唯一时只问一个定位问题。
2. 参考图只影响圈选区域，不得把参考造型扩散到整机。
3. 调用局部图片编辑能力生成结果，检查选区外像素/主体特征漂移、边界接缝、透视、材质和结构连续性。
4. 不合格结果不得列为成功输出；按 [references/deliverable-contract.md](references/deliverable-contract.md) 保存输入、掩膜、输出和历史。

## 边界

没有有效选区或局部描述时不猜测关键修改部位。视觉改型不等同于结构、强度或量产可行性验证。
