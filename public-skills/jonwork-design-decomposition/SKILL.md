# 智能设计解构

在生图前对两张图片做结构化设计分析，明确产品必要功能、参考造型/风格和当前等级允许迁移的字段。

## 统一交付闭环（强制）

- 先读取当前会话、项目、附件、Source 与上游产物，列出已具备、缺失、冲突及不适用材料；不得要求用户重复提供已有信息。
- 缺少会改变结果的参数或必需素材时，每轮最多询问 1–3 个关键问题并给推荐默认值；必需图片/选区/参考对象缺失时必须阻塞对应生成阶段，不得猜测或伪造。
- 生成前回显目标、输入角色、约束、输出格式、选定 Skill 与逐项验收标准；用户已明确批准相同 Brief 时直接继续。
- 输出必须是本技能交付契约规定的真实文件，并同步维护 `deliverable-brief.md` 与 schema v2 `deliverable-manifest.json`；每次修订递增版本且不覆盖已批准版本。
- 生成后打开或解析全部文件，逐项记录可读性、内容/视觉一致性、保护项、禁止项与失败证据。供应商或工具失败时保持 `draft`，只列真实成功文件。
- 只有真实产物存在、验收项全部有通过证据且用户明确批准后才能标记最终版；否则在右侧成果栏保持草稿、待确认或失败状态。


## 调用与路由

- 用户要求设计解构、拆解产品基因、判断参考图哪些内容可迁移时适用。
- 本技能输出结构化设计档案，不直接替代 `@造型融合` 的图片生成。

## 界面参数

- `productImage`：必填，用于识别并锁定必要功能。
- `referenceImage`：必填，用于提取造型与风格证据。
- `formAdmissionLevel`：1–7，默认 4。
- `styleAdmissionLevel`：1–7，默认 4。

## 自动执行

1. 对产品图拆分功能、组件、交互、几何层级、结构关系和不可变约束。
2. 对参考图拆分轮廓比例、体块、特征线、细节、CMF、纹理、光影和语义。
3. 建立字段级证据引用，区分观察、推断和未知；不得从单视角虚构背面或内部结构。
4. 根据两个准入等级计算允许、受限、禁止迁移字段。低等级仅开放表层字段，高等级逐步开放体块与风格字段，但必要功能永远锁定。
5. 按 [references/deliverable-contract.md](references/deliverable-contract.md) 生成设计档案与状态。等级变化只重算准入，不重复分析稳定证据。

## 边界

解构结论是设计判断，不是专利自由实施、工程测量或材料鉴定。证据不足必须标明待验证。
