# 图片转3D

使用当前任务中的产品图片实际生成 GLB 模型，并输出可追溯的输入、参数和质量检查。

## 统一交付闭环（强制）

- 先读取当前会话、项目、附件、Source 与上游产物，列出已具备、缺失、冲突及不适用材料；不得要求用户重复提供已有信息。
- 缺少会改变结果的参数或必需素材时，每轮最多询问 1–3 个关键问题并给推荐默认值；必需图片/选区/参考对象缺失时必须阻塞对应生成阶段，不得猜测或伪造。
- 生成前回显目标、输入角色、约束、输出格式、选定 Skill 与逐项验收标准；用户已明确批准相同 Brief 时直接继续。
- 输出必须是本技能交付契约规定的真实文件，并同步维护 `deliverable-brief.md` 与 schema v2 `deliverable-manifest.json`；每次修订递增版本且不覆盖已批准版本。
- 生成后打开或解析全部文件，逐项记录可读性、内容/视觉一致性、保护项、禁止项与失败证据。供应商或工具失败时保持 `draft`，只列真实成功文件。
- 只有真实产物存在、验收项全部有通过证据且用户明确批准后才能标记最终版；否则在右侧成果栏保持草稿、待确认或失败状态。


## 调用与路由

- 用户要求图片转 3D、生成 GLB、从多视角重建产品时适用。
- 仅做视觉效果图时使用相应图片生成 Skill，不用本技能伪造三维结果。

## 界面参数

- `inputMode`：单张图片或多视角图片。
- `images`：单张模式 1 张；多视角模式使用同一对象、尺度和版本的多张视图。
- `requirements`：可选，补充结构、材质或比例要求。
- `meshQuality`：草稿 50K、标准 100K、高 200K，默认标准。
- 可选输出：纹理、材质、简化模型；只在生成器支持时启用。

## 自动执行

1. 检查视图是否同一产品、遮挡和背景是否影响重建；多视角按正/侧/后/俯等视图标注。
2. 从设计提案继承比例和结构约束，未知背面或内部结构标为生成假设。
3. 调用可用三维生成能力实际生成 `.glb`；不得用二维旋转图、空文件或描述文字冒充模型。
4. 检查文件可读取、三角面级别、尺度/朝向、网格完整性、纹理引用和预览可用性。
5. 按 [references/deliverable-contract.md](references/deliverable-contract.md) 保存模型、预览和状态。

## 边界

如果当前环境没有三维生成器，直接说明“图片转3D能力不可用”，保留准备好的输入 Brief，但不宣称完成。生成模型不是工程 CAD，也不保证尺寸或可制造性。
