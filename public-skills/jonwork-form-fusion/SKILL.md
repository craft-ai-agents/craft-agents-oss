# 造型融合

以一张主体图和可选参考图为证据，保留产品身份的同时迁移可控的造型语言并生成新方案。

## 统一交付闭环（强制）

- 先读取当前会话、项目、附件、Source 与上游产物，列出已具备、缺失、冲突及不适用材料；不得要求用户重复提供已有信息。
- 缺少会改变结果的参数或必需素材时，每轮最多询问 1–3 个关键问题并给推荐默认值；必需图片/选区/参考对象缺失时必须阻塞对应生成阶段，不得猜测或伪造。
- 生成前回显目标、输入角色、约束、输出格式、选定 Skill 与逐项验收标准；用户已明确批准相同 Brief 时直接继续。
- 输出必须是本技能交付契约规定的真实文件，并同步维护 `deliverable-brief.md` 与 schema v2 `deliverable-manifest.json`；每次修订递增版本且不覆盖已批准版本。
- 生成后打开或解析全部文件，逐项记录可读性、内容/视觉一致性、保护项、禁止项与失败证据。供应商或工具失败时保持 `draft`，只列真实成功文件。
- 只有真实产物存在、验收项全部有通过证据且用户明确批准后才能标记最终版；否则在右侧成果栏保持草稿、待确认或失败状态。


## 调用与路由

- 用户要求“把参考图的造型语言融入主体”“融合两种产品形态”时适用。
- 指定多张图不同部位来源用 `@自定义模式`；只迁移颜色材质用 `@CMF发散`。

## 界面参数

- `productImage`：必填，主体完整、背景清晰。
- `styleReference`：可选，提供材质、光影、比例或造型语言。
- `designFeatures`：希望迁移与必须保留的特征。
- `advancedMode`：是否精细控制造型、风格和锁定特征线。
- `divergence`：高/中等/低，默认中等。
- 输出设置：比例 `1:1`/`3:2`/`2:3`、张数 1–4、质量低/中等/高；默认 `1:1`、1、中等。

## 自动执行

1. 分别提取主体的身份特征与参考图的可迁移语言，建立“保留/迁移/禁止复制”清单。
2. 根据发散度控制变化：低=表层与局部，高=比例、体块与特征线可明显重构，但不得违背锁定项。
3. 实际生成图片，并检查主体身份、融合自然度、结构合理性、细节连续性和参考图过拟合。
4. 按 [references/deliverable-contract.md](references/deliverable-contract.md) 保存结果、检查和历史状态。

## 边界

不得宣称参考产品的专利或品牌元素可合法迁移；明显标识默认不复制。图片生成失败时明确失败，不以文字方案替代界面要求的图片结果。
