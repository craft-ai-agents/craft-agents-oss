# 采购型号信息搜索

拿到一个采购/报价型号，用公开资料查清它是什么：可能品牌/制造商、品类、核心规格、封装/包装/温度/认证、生命周期，以及官方产品页、datasheet、订货说明、授权分销商 exact MPN 页面。

搜公开资料时优先原厂产品页和 datasheet；平台页面只作品牌/品类线索，不作官方规格结论。型号原文先保留，不要先归一化。

**优先原厂域名不只是更权威,也是因为分销商页面常年架着反爬**(保护的是他们的价格/库存,不是规格资料)。原厂自己的 datasheet PDF 通常零防护(实测直连即可,是他们希望被找到的营销材料)。搜索时直接带上制造商域名(如 `site:ti.com`/`site:onsemi.com`),不要等分销商页面打不开才想起原厂。

**分销商资料页确实打不开时**(反爬拦截页/验证页),按序尝试,别死磕同一页:
1. 换搜索词直接找原厂域名的同款资料(最常见的解法,分销商页面大多是转载原厂 datasheet)。
2. 静态资料(规格书/参数,不要求实时价格库存)可试 Wayback Machine:先 `curl "https://archive.org/wayback/available?url=<目标URL>"` 查有无快照,有则 `curl` 直接拉存档 URL 读内容——**WebFetch 工具本身进不去 `web.archive.org` 这个域名,必须用 Bash curl,不能指望 WebFetch 直接处理**。
3. **实测过 Jina Reader(`r.jina.ai/<url>`)——连续三次请求里两次被拦、一次返回型号对不上的错误内容,不可靠,不要用它当解法。**
4. 都不行,才写"本次未取到"(不是无这份资料)。

## 输出

给采购一张型号属性表:

| 字段 | 值 | 置信度 |
|---|---|---|
| 品牌 | TI(已确认) | 高 |
| 品类 | 运算放大器 | 高 |
| 核心规格 | ... | 中 |
| 封装 | SOIC-8 | 高 |
| 生命周期 | 量产 | 中 |
| 可用搜索写法 | ... | - |
| 公开资料链接 | ... | - |
| 未确认信息 | ... | - |

品牌/品类不清就在"值"列写"疑似/未知",置信度写低;资料页打不开/登录/验证/访问受限,在对应字段"值"列写"本次未取到"。

## 边界

- 只做型号识别，不查库存、不查报价、不判断替代。
- 品牌/品类不清就写”疑似/未知”和缺口，不硬猜。
- 页面打不开/登录/验证/访问受限写成本次未取到。

## Rationalization Table

| Excuse | Reality |
|---|---|
| “既然查到了平台页面，顺手报库存/价格。” | 本 skill 只识别型号信息；平台页面只能作品牌/品类线索。 |
| “型号看起来像某品牌，就直接写确认。” | 品牌/品类不清要写疑似或未知，并列缺口。 |
| “先把型号规范化再搜更干净。” | 型号原文先保留；归一化可能抹掉后缀、封装和包装信息。 |
| “资料页打不开，就跳过不说。” | 页面打不开、登录、验证、访问受限都要写成本次未取到——但先按上面的序列试过原厂域名/Wayback 再下结论，别第一次打不开就放弃。 |
| “试试 Jina 之类的代理服务绕开拦截。” | 实测不可靠（连续失败+返回错误内容），不要用它当解法。 |
