## 一、接收询价

询价从飞书群「询报价群」接收，由「紧急调度客户需求项目管理表」自动推送。

**推送格式：**

```
客户需求: <编号>  等级<A/B/C/D>
【紧急询报价】<时间>
  客户：<客户名>
  规格型号：<型号>
  数量：<数量>
  品牌：<品牌>
  询价时间：<时间>
  预计花费时间：<Xh>
  有无附件：<有/无>
  备注：<备注>
  采购负责人：@<姓名>
```

**注意事项：**

- 收到询价需求需及时安排分配
- D 类客户可以先问对方是否有目标价
- 初步判断需求数量是否市场现货能满足，可以先请业务确认是要现货还是要期货

## 二、询料

根据客户询价型号、客户等级和预计花费时间等信息，合理安排时间和精力进行询价，并在【采购询价表】中录入询价信息。

### 1. 产品信息完整

#### 1.1 常规通用料询价方式

##### 1.1.1 确定自家库存

| 步骤 | 具体操作 | 参考文件 |
|------|---------|---------|
| ① 查印诺库存 | 查【供应商管理（正式版）】→ 查找库存表，确定囤货成本，对比行情售价 | 供应商管理（正式版） |
| ② 查第三方行情 | IC 网等第三方数据网查看，通过双凯杰进行售价，对比行情售价 | — |
| ③ 查往年询价 | 查询往年询价汇总表，向报过价的供应商询价，对比行情售价 | 紧急调度业务25年前九月数据 / 采购询价表 |

##### 1.1.2 根据产品分类找料

不同品类的找料渠道和优先级不同：

| 品类 | 找料渠道（按优先级） |
|------|-------------------|
| **芯片 / 电容电解类** | ① IC 网华强市场询价 → ② 贸泽 Mouser / 得捷 Digikey 等现货平台 → ③ 第三方电子平台 → ④ Google / 百度 → ⑤ 代理 / 经销商 |
| **连接器** | ① QQ 群 → ② 代理 / 经销商 → ③ 立创等现货平台 → ④ 第三方电子平台 → ⑤ Google / 百度 |
| **工控产品** | ① QQ 群 → ② 代理 / 经销商 → ③ 第三方电子平台 → ④ Google / 百度 |

**注意事项：**

1. 供应商询价**至少 2-3 家**，对比单价
2. 料号信息需完整
3. 比较重的产品需确认重量
4. 平台库存注意限制品牌及型号，部分国外平台是否能发境外，有些平台只与本国公司主体合作或只发本国地址
5. 新平台或新供应商需确认库存信息真实性，型号和客户需求型号是否一致（**尤其是华强北供应商**）
6. 务必核对供应商交期：是交期还是现货

#### 1.2 客户定制

需确定产品基本参数（参数、性能、价格、MOQ、交期、规格书）。

| 客户重要程度 | 找料渠道 |
|------------|---------|
| **重要**（找工厂） | ① 百度 → ② 1688 / 淘宝 → ③ 合作过的供应商 → ④ 抖音 / AI |
| **不重要**（找工厂） | ① 百度 → ② 1688 / 淘宝 |

#### 1.3 期货需求

参考常规料询价方式，在【采购询价表】中填写询价信息。

### 2. 产品信息不完整

| 客户重要程度 | 场景 | 操作 | 注意事项 |
|------------|------|------|---------|
| **重要** | 只有规格书或图纸 | ① AI 确定产品型号及规格 ② 推荐替代产品 | 需确定参数、性能、价格、MOQ、交期、规格书 |
| **重要** | 只有型号没有需求数量 | 按最小包装数确认：芯片→徐总（华强北）；其他→按常规通用料处理 | |
| **重要** | 只有产品照片 | ① 1688 / 淘宝搜索 ② AI 分析产品 ③ 规格书与业务确认 | |
| **重要** | 按产品系列找 | 代理 / 经销商确认 | |
| **不重要** | — | 反馈给业务确认消息 | |

## 三、订单采购

客户下单后，收到业务发来的订单，安排采购。

**订单审批信息包含：**

- 内部订单管理号（OD 开头）
- 订单日期 / 预计交期
- 客户全称 / 客户窗口
- 交易条件（DDU / FOB 等）
- 下单型号 / 数量 / 计量单位

## 四、供应商管理

### 供应商三大池

| 池子 | 定义 | 进入标准 |
|------|------|---------|
| **供应商档案** | 已完成基础联系与信息收集，具备跟进/筛选/合作价值 | 已完成建联（完整名称 + 优势产品匹配 + 实际沟通记录 + 真实联系信息） |
| **待维护** | 已纳入视野，尚未完成有效联系或信息收集 | 发现但未联系 / 已联系未找到有效对接人 / 仅有初步信息 / 信息不足待补充 |
| **黑名单** | 明确不纳入合作、不再维护 | 收款主体异常 / 信息不透明 / 无法联系 / 虚假报价/失信/假货 / 高风险 / 内部确认不再合作 |

### 供应商评分体系

**总分 = (类型×30% + 库存表×25% + 价格×20% + 风险×25%) × 20**（满分 100 分）

| 维度 | 权重 | 说明 |
|------|------|------|
| 供应商类型 | 30% | 原厂/代理/经销商/贸易商等 |
| 是否提供库存表 | 25% | 定期提供完整库存表得高分 |
| 价格竞争力 | 20% | 与市场主流价对比（参考其他供应商报价或平台公开价） |
| 付款风险 | 25% | 按付款条件 + 地区风险分级 |

**付款风险分级：**

| 付款对象标签 | 分数 |
|------------|------|
| 货到付款 / 月结（普通地区 / 风险地区） | 5 分 |
| 平台预付（普通地区） | 4 分 |
| 一般预付（普通地区） | 3 分 |
| 平台预付（风险地区） | 2 分 |
| 一般预付（风险地区） | 1 分 |

- **普通地区**：中、日、韩、欧、美
- **风险地区**：除普通地区之外的所有地区

### 供应商流转

- 【采购询价表】记录的供应商 → 自动流入【待维护】
- 【待维护】信息填完 → 点击"已维护" → 流入【供应商档案】
- 供应商档案/待维护 → 点击"申请拉黑" → 推送至采购例会群 → 周三例会审核 → 通过后流入【黑名单】

## 五、品牌名称标准化规则

### 规则

1. 所有品牌名称以**官方写法**为准
2. 语言优先级：英文优先，其次品牌所在国语言
3. 有官方大小写格式→按官方（如 `Panasonic`）；无规范→全大写（如 `KOA`）
4. 多品牌同一单元格→按逗号拆分
