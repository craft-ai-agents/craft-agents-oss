# 平台报价查找

本 skill 负责采购业务层的平台结果整理。这里按采购需要处理采集层返回的结构化证据。

## 工作流

1. 确认入口：本地库存已经查完为空，或用户明确要求继续查外部平台。
2. 保留用户原始型号：不要先合并后缀、包装、温度等级或版本号。
3. 首轮必须直接平台全覆盖：准确度优先，首轮覆盖全部直接库存/报价平台；不要因为耗时只查少数平台。
4. 首轮不要跑聚合平台或替代候选源：聚合平台会重复覆盖多个真实平台，替代候选源不是普通库存报价平台；二者都不能算首轮直接平台覆盖。
5. 展示搜索覆盖：每次输出都先列出本次实际查询的网站/source 覆盖。首轮列直接平台；二轮列聚合平台（如有）；没有跑聚合平台就写“二轮聚合：未使用”。覆盖清单必须来自本次实际传入的 source 和返回的 rows/errors，不能凭印象补。
6. 核对首轮覆盖状态：每个直接平台都必须落到一种状态：有结果、正常无匹配、本次未取到、访问受限、维护/连接问题。只有每个直接平台都有状态，才能写“首轮直接平台已覆盖完成”；若有平台状态缺失，写“仍有平台状态未确认”，不要写全平台完成。
7. 二轮只补缺口：首轮后仍无足够结果、存在访问受限/状态缺失、需要交叉验证或长尾补充时，才补跑聚合平台。替代候选源只在任务转为替代料判断时使用，不混入普通平台报价结果。
8. 取得结构化平台证据：只消费返回的型号、平台、品牌、描述、库存、价格、MOQ、交期、链接和错误状态。
9. 做型号一致性核对：平台返回型号与用户型号不完全一致时，逐字符写清差异，例如多了包装后缀、少了温度等级、版本字母不同。
10. 合并同一平台的重复行：同平台同型号保留库存/价格最完整的行，证据链接不同但信息互补时可以合并到同一行。
11. 区分状态：有结果、正常无匹配、本次未取到要分开写；访问受限或报错只能说本次未取到，不能说成无货。

## 输出

输出给采购看平台证据，不输出采集过程。没有上层指定格式时，用下面的结构：

```text
结论：首轮直接平台已覆盖完成/仍有平台状态未确认；查到 X 条可核对结果；Y 个平台未返回匹配；Z 个平台本次未取到。

搜索覆盖：
- 首轮直接平台：<source-id1>, <source-id2>, ...
- 二轮聚合：未使用 / <source-id1>, <source-id2>, ...
- 未确认平台：无 / <source-id：原因>

首轮直接平台结果：
| 平台 | 返回型号 | 型号一致性 | 品牌/描述 | 库存 | 价格/MOQ | 交期 | 证据 | 状态/需确认 |
|---|---|---|---|---|---|---|---|---|
| ... | ... | 完全一致 / 差异：... | ... | ... | ... | ... | ... | ... |

未返回匹配/本次未取到：
- <平台>：未返回匹配 / 本次未取到（原因：...）

二轮聚合补充（如有）：
- <聚合来源>：<补充到的结果或交叉验证信息>
```

写法要求：

- `结论` 只概括首轮直接平台覆盖结果和结果数量，不写采购建议。
- `搜索覆盖` 必须出现，使用本次实际查询的 source id；首轮不出现聚合平台。
- 首轮和二轮分开展示；聚合补充不能混进首轮直接平台结果。
- `型号一致性` 必须具体；不要只写“需复核”。
- `库存`、`价格/MOQ`、`交期` 没有证据就写“未返回”，不要补猜。
- `证据` 优先给产品页或 datasheet 链接；没有链接就写来源字段。
- 如果上层要求 JSON、表单字段或批量汇总格式，按上层格式映射这些字段，不套用本表格。

## 反合理化表格

| 常见借口 | 反驳 |
|---|---|
| “聚合平台覆盖了很多平台，首轮一起跑更全面。” | 首轮要确认每个直接平台的真实状态；聚合平台只能二轮补缺或交叉验证，不能替代直接平台覆盖。 |
| “首轮跑了一批平台，就可以说全平台完成。” | 只有全部直接库存/报价平台都有状态，才能说首轮直接平台已覆盖完成；缺状态就必须写未确认。 |
| “平台没返回结果，就是无货。” | 正常无匹配和本次未取到要分开；访问受限不是无货证据。 |
| “型号差一个后缀也算同一个。” | 后缀可能代表包装、温度、速度、版本或封装，必须逐字符说明差异。 |
| “看到价格最低的一行，直接推荐给采购。” | 本 skill 只汇总平台证据；不做供应商准入、下单建议或性价比排序。 |
| “WebSearch 看到库存页，也能报库存价格。” | 库存、价格、可得性只认结构化平台证据；网页搜索只能辅助识别型号信息。 |
| “平台返回 similar/alternate，就能当替代料。” | 平台相似项只是线索，不能在这里下可替代结论。 |
