# 配方:库存跨 7 表查询(procurement-local-inventory-lookup 用)

库存 = 7 张表:动态库存表(动态)/自家库存(自家)/A级供应商库存(A)/B级供应商库存1-3(B1/B2/B3)/C级供应商库存(C)。

**列名规则(必守,不守必炸):SQL 里所有列名一律双引号。** 这些表里有 `目标价/价格`、`含税/未税`(裸写被当除法)、`采购负责人 (人员 )`(带空格括号)这类列;全引号是唯一不用逐列判断的写法。

各表字段名**不一致**(动态库存表的库存列叫 `数量`、价格列叫 `目标价/价格`、时间列叫 `发布时间`;A/B/C/自家叫 `库存数量`/`单价`/`更新时间`),列名会随业务漂移,**先 `larkdepot schema` 核对**,再套模板。以下模板列名与 2026-07-06 schema 一致:

    larkdepot query sql --sql "
      SELECT '动态' AS 等级, \"型号\", \"品牌\", \"数量\" AS 库存, \"目标价/价格\" AS 单价, \"供应商名称\" AS 供应商, \"发布时间\" AS 时间
      FROM 动态库存表 WHERE norm(\"型号\")=norm('<型号>')
      UNION ALL
      SELECT '自家', \"型号\", \"品牌\", \"库存数量\", \"单价\", NULL, \"更新时间\"
      FROM 自家库存 WHERE norm(\"型号\")=norm('<型号>')
      UNION ALL
      SELECT 'A', \"型号\", \"品牌\", \"库存数量\", \"单价\", \"供应商名称\", \"更新时间\"
      FROM A级供应商库存 WHERE norm(\"型号\")=norm('<型号>')
      UNION ALL
      -- B1/B2/B3/C 四张表与 A 同构(表名换成 B级供应商库存1/2/3、C级供应商库存),列名以 schema 输出为准
    "

- 每张表用 `norm(<该表的型号列>)=norm('<型号>')` 各自匹配,`UNION ALL` 一次查完全部等级,别漏表。
- `norm()` 已做变体归一(去 `-`/`/`/空格+大写),NULL 行安全跳过;不必造变体词逐表试。近似命中(如尾缀差异)工具不会替你判断,SQL 命中后自己逐字符复核。
- envelope `freshness.synced_at` 随行返回,给业务侧展示"缓存快照时间"用。
