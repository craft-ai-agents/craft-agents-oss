# 配方:库存跨 7 表查询(procurement-local-inventory-lookup 用)

库存 = 7 张表:动态库存表(动态)/自家库存(自家)/A级供应商库存(A)/B级供应商库存1-3(B1/B2/B3)/C级供应商库存(C)。所有库存表的型号列都叫「型号」,一条命令搜完全部:

    larkdepot base +record-search --keyword "<型号>" --search-field 型号 --limit 100

- 省 `--table-id` = 搜全部缓存表(供应商档案没有「型号」列,自动跳过,不用排除)。
- 变体归一自动做(去 `-`/`/`/空格+大写,bav-99 命中 BAV99),**不必造变体词逐表试**;近似命中(如尾缀差异)工具不会替你判断,命中后自己逐字符复核。
- 每行自带 `_table` 说明来自哪张表(即库存等级);各表列名不一致(动态表:`数量`/`目标价/价格`/`发布时间`;A/B/C/自家:`库存数量`/`单价`/`更新时间`),整行返回按各表自己的列读,不需要对齐。
- envelope `freshness.synced_at` 随行返回,给业务侧展示"缓存快照时间"用。
- 需要聚合(比如按供应商合计库存)才降到 `query sql`,列名一律双引号,先 `larkdepot schema` 核对。
