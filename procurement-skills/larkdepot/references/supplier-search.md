# 配方:供应商档案三字段检索(procurement-supplier-shortlist 用)

查**供应商档案**一张表,品牌/品类跨「主营品牌」「优势产品」「询价品牌」三列匹配(**先 `larkdepot schema` 核对真实列名**):

    larkdepot query sql --sql "
      SELECT 供应商全称,供应商类型,供应商等级,主营品牌,优势产品,联系方式,联系媒介,\"官网|店铺\",供应商状态,备注,总分
      FROM 供应商档案
      WHERE 主营品牌 LIKE '%<关键词>%' OR 优势产品 LIKE '%<关键词>%' OR 询价品牌 LIKE '%<关键词>%'
    " --limit 50

- 中英文品牌各查一次(两条 SQL 或 OR 拼一条),结果合并去重。
- 列名带 `|` 等特殊字符要加双引号(如 `"官网|店铺"`)。
- 品类词(继电器/连接器)直接当关键词——优势产品列会命中。
