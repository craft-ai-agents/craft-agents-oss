# 本地库存查询

输入一个型号,给采购展示库存线索。**只读,不往任何表写数据。**

不做比价、供应商真假、下单建议、替代料判断。

## 怎么查

**查询一律走 `larkdepot` skill,一切工具细节(怎么查、结果怎么读、缓存好坏怎么判、坏了怎么降级)都以它为准,本 skill 只讲业务。**

业务口径:库存 = 这 7 张表,一次查全、别漏——

| 表名 | 等级标签 |
|---|---|
| 动态库存表 | 动态 |
| 自家库存 | 自家 |
| A级供应商库存 | A |
| B级供应商库存1/2/3 | B1/B2/B3 |
| C级供应商库存 | C |

- 各表字段名不完全一致(型号列可能叫"型号"/"品名"/"料号"等),以工具的自描述输出为准,不要凭记忆硬编码。
- 型号写法差异(连字符/空格/斜杠/大小写/尾缀)的归一匹配由工具完成,**不必自己造变体词逐表试**;近似命中自己逐字符复核。

## 输出

给采购一张库存明细表,按等级聚合;结果为空就如实写"本地无库存记录(截至缓存同步时间)"。

| 等级 | 型号 | 匹配 | 库存 | 单价 | 供应商 | 更新时间 | 备注 |
|---|---|---|---|---|---|---|---|
| 自家 | 55A0111-24-2 | 完全一致 | 500 | ¥3.20(囤货成本) | - | 2026-06-30 | - |
| A | 55A0111-24-2L | 模糊 | 1200 | ¥3.50 | XX电子 | 2026-06-28 | 差异:多了后缀 L |
| 动态 | 55A0111-24-2 | 完全一致 | - | ¥3.10 | YY贸易 | 2026-06-29 | 求购记录,非现货 |

写法要求:

- **动态库存表**(等级=`动态`)单独一行,类型是出货还是求购、发布时间写进"备注",时效性强,让采购判断新旧。
- **自家库存**(等级=`自家`)单独一行,"单价"列注明是囤货成本,方便采购对比市场行情。
- **型号逐字符比对**:模糊命中的行,"匹配"列写"模糊","备注"列逐字符写清差在哪——"差异:多了后缀 L"。不要只写"相近命中需复核"这种模糊话。
- **跨表交叉验证**:同型号只有一张表(一家供应商)报有货、其他等级全无 → 备注标"仅此一家报有货,无其他源印证"。多家有货时比较单价,某家明显偏低(低 30%+)在备注标出。A 级可信度高于 C 级——A 级无货但 C 级有货时在备注写清楚等级差异。
- 表后带上缓存同步时间,并提醒"为缓存快照,下单前对中标行可再实时复核"。

> 只挑库存相关字段(型号/库存/单价/供应商/等级)给采购,别整段结果照搬。

## 空结果与降级

**空结果是权威答案**(缓存是完整镜像,依据见 larkdepot skill)——如实写"本地无库存记录",到此为止。仅当采购**明确要求**对某个型号做最新核实时,才对那一个型号实时查一次。

**仅当 larkdepot skill 判定缓存不可用时**,按它的降级直查流程走;本 skill 只声明业务检索口径:**7 张库存表逐张按「型号」字段搜关键词**。降级也失败就如实告知,不要编造库存。

## 边界

有库存 ≠ 可下单。型号扩展/合并不等于型号等价。只读,不写 `查找库存` 或任何表。

## Rationalization Table

| Excuse | Reality |
|---|---|
| “缓存查不到，肯定是工具漏了，我再实时查一遍。” | 缓存是完整镜像，空结果就是权威答案；降级判定与流程以 larkdepot skill 为准。 |
| “我自己造几个变体逐表查更保险。” | 型号归一匹配已由工具完成，重复查会慢且引入冲突。 |
| “模糊命中就算有货。” | 模糊命中必须逐字符说明差异，不能当作型号完全一致。 |
| “把结果全贴出来最完整。” | 只给采购库存相关字段和必要核对点。 |
