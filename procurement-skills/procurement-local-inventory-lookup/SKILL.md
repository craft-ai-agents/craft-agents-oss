# 本地库存查询

输入一个型号，用 `lark-cli base --as user` 命令查飞书 Base 的本地/供应商库存，给采购展示库存线索。**只读，不往任何表写数据。**

不做比价、供应商真假、下单建议、替代料判断。

## 核心逻辑

直接查 7 张源表（动态库存表 + A/B1/B2/B3/C 级 + 自家），自己聚合结果。不依赖也不写 `查找库存` 汇总表（那张需要人工填型号，多数型号不在里面）。

## 数据源（飞书 Base，base-token `Mjlkb49B9aoptssVw8Jc0wGwnhh`；搜索字段都是 `型号`）

**供应商库存源表**（按等级分表）：

| 表名 | table-id | 说明 |
|------|----------|------|
| A级供应商库存 | `tblzQbSnVNhGszYA` | 核心供应商 |
| B级供应商库存1 | `tbldOthm6zmFonDM` | |
| B级供应商库存2 | `tblqaoi5UuUGybxF` | |
| B级供应商库存3 | `tbld53dBj2dvI1R6` | |
| C级供应商库存 | `tblBbvvRKB0Ziioz` | |
| 自家库存 | `tblSUjXdehzkxIbK` | 公司自有 |
| **动态库存表** | `tbli1WYTb1Xn2MSa` | 实时供需动态（出货/求购），时效性强 |

- 供应商库存字段：`型号 / 品牌 / 库存数量 / 单价 / MOQ / SPQ / 供应商名称 / 供应商等级 / 批次 / 含税未税 / 更新时间`
- 动态库存表字段：`型号 / 品牌 / 数量 / 目标价/价格 / 供应商名称 / 类型（出货/求购）/ 批次 / 发布时间`

## 搜索关键词策略

用户给的型号可能跟库存表里的写法有差异（连字符、空格、后缀）。查之前先准备搜索词列表：

1. **原始词**：用户原文，原样。
2. **去符号词**：去掉 `-` 空格 `/`。例如 `SML-M13UTT86S` → `SMLM13UTT86S`。
3. **核心词**：去掉尾部 1-2 个封装/等级后缀字符（S/T6/TR/L/P 等常见尾缀）。例如 `SML-M13UTT86S` → `SML-M13UTT86`。

去重后通常 2-3 个词。

**每张表的查询逻辑**：先用原始词查；如果返回 0 条，换下一个变体再查一次。一旦命中就停，不必把所有变体都查一遍。变体命中的结果在输出中标注"模糊匹配，需确认型号是否一致"。

## 怎么查

业务 Base《供应商管理（正式版）》当前用 `--as user` 查询。若默认身份或 `--as bot` 返回 `91403 you don't have permission`，切到 `--as user` 后重试一次并说明身份差异。

注意子命令必须带 **`+`** 前缀，写 `record-search` 不带 `+` 会失败。

    lark-cli base +record-search --as user --base-token Mjlkb49B9aoptssVw8Jc0wGwnhh --table-id <table-id> --json '{"keyword":"<搜索词>","search_fields":["型号"]}'

### 并发限制：最多 2 个同时查

飞书 Base record-search 有频率限制（错误码 `800004135`）。**最多 2 张表同时查，不要超过 2 个并发**。

按以下分组两两并行（一组完成再下一组）：
1. 动态库存表 + 自家库存
2. A级 + B1
3. B2 + B3
4. C级

遇到 `800004135`（limited）：等几秒重试直到成功，静默处理，不用告诉用户。

把各表命中的 `库存数量 / 单价 / 供应商名称 / 供应商等级` 聚合成一个跨级结果给采购。

## 输出

按等级聚合，给采购可用线索：

- **动态库存表**：有无出货/求购记录、供应商、数量、价格、发布时间。动态表时效性强，注明发布日期让采购判断新旧。
- 各级（A/B1/B2/B3/C）有没有货、哪家供应商、库存数量、单价；**自家库存单列，并把单价（囤货成本）标出来**，方便采购对比市场行情。
- **型号逐字符比对**：每条命中结果，把返回的型号和用户原始型号逐字符比较。有差异就写清楚差在哪——“你要的是 `55A0111-24-2`，这条是 `55A0111-24-2L`，多了后缀 L”。不要只写”相近命中需复核”这种模糊话。
- **跨表交叉验证**：同型号只有一张表（一家供应商）报有货、其他等级全无 → 标注”仅此一家报有货，无其他源印证”。多家有货时比较单价，某家明显偏低（低 30%+）就标出。A 级结果可信度高于 C 级——如果 A 级无货但 C 级有货，把等级差异写清楚。
- **供应商只有 1 家**：全部结果只有 1 家有货时，在 AGENTS.md 层面会自动补查供应商档案。这里只需如实呈现查到的数据。
- 全都没命中就如实写”本地无库存记录”。

> - 只挑库存相关的（型号/库存数量/单价/供应商/等级）给采购，别整表照搬。
> - 若 `--as user` 返回 `permission`/`scope` 或登录失效错误，**如实告诉用户需要给当前用户开 base 读权限 / 重新登录 lark-cli**，不要编造库存；不要反复切换身份重试。

## 边界

有库存 ≠ 可下单。型号扩展/合并不等于型号等价。只读源表自己聚合，不写 `查找库存` 或任何表。
